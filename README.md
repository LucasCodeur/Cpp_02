# CPP Module 02

## Overview

**CPP Module 02** focuses on ad-hoc polymorphism and operator overloading through the implementation of a **Fixed-point number class**.

The module introduces the idea of representing numerical values using a fixed-point representation and provides extensive practice with operator overloading.

## Objectives

* Implement a fixed-point number class.
* Understand fixed-point representation.
* Overload arithmetic operators.
* Overload comparison operators.
* Overload increment and decrement operators.
* Implement conversions between integer, floating-point, and fixed-point values.
* Provide stream output for custom types.

## Skills Developed

* **C++**
* Operator overloading
* Fixed-point arithmetic
* Constructors and conversion
* Comparison operators
* Arithmetic operators
* Increment and decrement operators
* Stream operators
* Class design

## What I Learned

This module helped me understand how C++ allows custom types to behave naturally through operator overloading, while introducing the principles behind fixed-point numerical representation.
